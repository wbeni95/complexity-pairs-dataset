# When binary powering is exact in a magma

> **Provenance: own result** (elementary). The literature search described under
> [Literature search](#literature-search) found no source that states these conditions. This is a statement about
> that search, not a claim of priority.

Binary powering (square-and-multiply) computes x^e with at most 2⌊log₂ e⌋ products (Remark 5). In a monoid, or
more generally in any power-associative magma, it is correct (Remark 1). This note asks exactly when it is correct
in a **magma**, a set with an arbitrary binary operation. The
answer is a condition on the left powers of x alone, different for the left-to-right and the two right-to-left
variants, and it can be checked in finitely many steps when the powers of x are eventually periodic.

## Definitions

Let (M, ·) be a magma: a set with a binary operation, no axioms. Fix x ∈ M.

- **Left powers:** p_1 = x and p_(k+1) = p_k · x. "Binary powering is exact for x" means that it returns p_e for
  every exponent e ≥ 1.
- **LTR (left to right):** r ← x; for each bit of e after the leading one, r ← r·r, and then r ← r·x if the bit is
  1. Write B(e) for the result. Equivalently, B(1) = x, B(2a) = B(a)·B(a) and B(2a+1) = B(2a)·x.
- **RTL (right to left):** s_0 = x and s_(k+1) = s_k·s_k. Scan the bits of e from the least significant one. At
  the first set bit k, r ← s_k. At every later set bit k, r ← r·s_k (variant **RTL-L**) or r ← s_k·r (variant
  **RTL-R**). Return r. No identity element is needed.
- **Conditions on x:**
  - SQ(x): p_a · p_a = p_(2a) for all a ≥ 1;
  - CL(x): p_a · p_(2^k) = p_(a+2^k) for all k ≥ 0 and 1 ≤ a ≤ 2^k;
  - CR(x): p_(2^k) · p_a = p_(a+2^k) for the same range;
  - PA(x): p_a · p_b = p_(a+b) for all a, b ≥ 1. PA(x) holds for every x iff M is power-associative (the
    submagma generated by each x is associative): if PA(x), the set {p_k} contains x, is closed under ·, and
    p_a·p_b = p_(a+b) is associative; conversely, in an associative submagma p_a·p_b = p_(a+b) by induction on b.
- **Eventual periodicity:** the left powers are *eventually periodic with preperiod μ ≥ 1 and period λ ≥ 1* if
  p_(k+λ) = p_k for all k ≥ μ. If M has m elements, two of p_1, …, p_(m+1) coincide, say p_i = p_j with i < j.
  Since p_(k+1) depends only on p_k, p_(i+t) = p_(j+t) for all t ≥ 0, so μ = i and λ = j − i work, and μ + λ ≤ m + 1.

## Statement

**Theorem 1 (LTR; any magma).** (a) B(e) = p_e for all e ≥ 1 if and only if SQ(x).
(b) *Finite form.* For every E ≥ 1: B(e) = p_e for all e ≤ E if and only if p_a·p_a = p_(2a) for all
a ≤ ⌊E/2⌋. Hence, if a* is the smallest a with p_a·p_a ≠ p_(2a), the smallest wrong exponent is exactly 2a*.

**Theorem 2 (RTL; any magma).** (a) RTL-L returns p_e for all e ≥ 1 if and only if CL(x), and RTL-R does if and
only if CR(x). (b) *Finite form.* For every K ≥ 0: RTL-L returns p_e for all e ≤ 2^(K+1) if and only if
p_a·p_(2^k) = p_(a+2^k) for all k ≤ K and 1 ≤ a ≤ 2^k; the same for RTL-R and CR.

**Theorem 3 (finite check for LTR).** If the left powers of x are eventually periodic with preperiod μ and period
λ, then SQ(x) holds if and only if p_a·p_a = p_(2a) for all 1 ≤ a ≤ μ + λ − 1. In a magma with m elements it
therefore suffices to check a ≤ m. The bound is tight: for every m ≥ 2 there is a magma with m elements and an x
for which the condition holds for a = 1, …, m − 1 and fails at a = m.

**Proposition 4 (finite check for RTL).** Let the left powers of x be eventually periodic with preperiod μ and
period λ, h = μ + λ − 1 and K₁ = ⌈log₂ h⌉. Then CL(x) holds if and only if p_a·p_(2^k) = p_(a+2^k) for all
0 ≤ k ≤ K₁ + λ − 1 and 1 ≤ a ≤ min(2^k, h). The same holds for CR(x).

**Proposition 5 (relations).** PA(x) implies SQ(x), CL(x) and CR(x). The three conditions SQ, CL, CR are pairwise
independent; in fact all 8 combinations of their truth values occur at a single element of a magma with at most 3
elements (table below). SQ, CL and CR at every element do not imply power-associativity.

In words: left-to-right powering needs exactly that squaring a left power gives the left power of twice the
exponent; right-to-left powering needs that multiplying a left power by a left power of a power-of-two exponent,
on the correct side, is additive. Neither needs associativity, and neither implies the other.

## Proofs

*Theorem 1(a).* (⇐) By strong induction on e. B(1) = x = p_1. If e = 2a, then B(e) = B(a)·B(a) = p_a·p_a = p_(2a) by
the induction hypothesis and SQ at a. If e = 2a + 1, then B(e) = B(2a)·x = p_(2a)·x = p_(2a+1) by the induction
hypothesis and the definition of left powers. (⇒) For every a ≥ 1, p_(2a) = B(2a) = B(a)·B(a) = p_a·p_a. The loop
form computes the same B: after reading the binary prefix a of e, r = B(a), and a further bit b gives B(2a) and,
if b = 1, B(2a + 1). ∎

*Theorem 1(b).* The induction for e ≤ E uses SQ only at a = ⌊e/2⌋ ≤ ⌊E/2⌋. Conversely, for a ≤ ⌊E/2⌋ we have
2a ≤ E, and the (⇒) step applies. For the first wrong exponent apply this equivalence with E = 2a* − 1 (all
correct) and with E = 2a* (not all correct). ∎

*Theorem 2(a) (RTL-L; RTL-R is the mirror image).* (⇐) First, s_k = p_(2^k) for all k by induction:
s_(k+1) = s_k·s_k = p_(2^k)·p_(2^k) = p_(2^(k+1)), by CL with a = 2^k. Now let e have highest set bit k and
a = e − 2^k, so 0 ≤ a < 2^k. The run on e treats the bits 0, …, k − 1 exactly as the run on a (zero bits above the
highest set bit of a change nothing), so just before bit k, r is undefined (a = 0) or equals RTL(a). The output is
s_k = p_(2^k) = p_e if a = 0, and RTL(a)·s_k = p_a·p_(2^k) = p_e otherwise, by induction on e and CL. (⇒) The
exponent e = 2^k gives s_k = p_(2^k) for every k, hence p_(2^k)·p_(2^k) = s_(k+1) = p_(2^(k+1)), which is CL with
a = 2^k. The exponent e = a + 2^k with 1 ≤ a < 2^k gives p_a·p_(2^k) = RTL(e) = p_e. ∎

*Theorem 2(b).* The exponents e ≤ 2^(K+1) are 2^k (k ≤ K + 1) and a + 2^k with k ≤ K and 1 ≤ a < 2^k. The proof
above uses, for these e, exactly CL(k, a) for k ≤ K and 1 ≤ a < 2^k, and CL(k, 2^k) for k ≤ K (to get
s_(k+1) = p_(2^(k+1))); and conversely each of these conditions follows from the correctness at one of these
exponents. ∎

*Theorem 3.* For a ≥ μ, both p_a and p_(2a) are periodic in a with period λ (2a ≥ μ as well). So the truth of
p_a·p_a = p_(2a) is λ-periodic on a ≥ μ, and its values there are those on μ ≤ a ≤ μ + λ − 1. With μ + λ ≤ m + 1,
the bound is ≤ m.

*Tightness.* On {0, …, m − 1} let x = 0 and define T[k][0] = min(k + 1, m − 1) for all k,
T[a − 1][a − 1] = min(2a, m) − 1 for 1 ≤ a < m, T[m − 1][m − 1] = 0, and T = 0 in every other cell (the cell (0, 0)
gets the value 1 from both rules). Then p_k = min(k, m) − 1 by induction (p_(k+1) = T[p_k][0]). For a < m,
p_a·p_a = T[a − 1][a − 1] = min(2a, m) − 1 = p_(2a). At a = m, p_m·p_m = T[m − 1][m − 1] = 0 ≠ m − 1 = p_(2m). Here
μ = m and λ = 1, so μ + λ − 1 = m, and by Theorem 1(b) the first wrong exponent is 2m. Since m is arbitrary, no bound
on a that does not depend on the magma suffices. ∎

*Proposition 4.* Reduction in a: for a ≥ μ, p_a and p_(a+2^k) depend only on a mod λ, so CL(k, a) equals
CL(k, a′) for the a′ ∈ [μ, μ + λ − 1] with a′ ≡ a (mod λ), and a′ ≤ a ≤ 2^k. So a ≤ min(2^k, h) suffices.
Reduction in k: for k ≥ K₁ we have 2^k ≥ h ≥ μ, the range of a is [1, h], and p_(2^k) and p_(a+2^k) depend only on
2^k mod λ. Write λ = 2^v·λ′ with λ′ odd. Since K₁ ≥ log₂ λ ≥ v, the sequence 2^k mod λ is purely periodic for
k ≥ K₁, with period ord_λ′(2) ≤ λ′ ≤ λ (for k ≥ v it is determined by 2^k mod λ′, and 2 is invertible mod λ′). So
every value of 2^k mod λ with k ≥ K₁ already occurs for some k ≤ K₁ + λ − 1. ∎

*Proposition 5.* PA(x) contains SQ, CL and CR as special cases. Each witness below is a finite statement, and
[verify.py](verify.py) decides it exactly: SQ, CL and CR through Theorem 3 and Proposition 4, PA through Remark 3,
and in addition by running the three algorithms for all e ≤ 64. Tables are written as rows, T[a][b] = a·b:

| SQ(x) | CL(x) | CR(x) | table | x |
|---|---|---|---|---|
| no | no | no | [[1,0],[0,0]] | 0 |
| no | no | yes | [[0,0,1],[0,1,0],[0,1,1]] | 2 |
| no | yes | no | [[0,0,1],[1,1,0],[0,0,1]] | 2 |
| no | yes | yes | [[0,0,1],[0,1,0],[0,0,1]] | 2 |
| yes | no | no | [[0,0,1],[0,0,0],[0,0,0]] | 2 |
| yes | no | yes | [[0,0],[1,0]] | 1 |
| yes | yes | no | [[0,0,1],[0,2,0],[0,0,0]] | 1 |
| yes | yes | yes | [[0,0],[0,0]] | 0 |

For example, in [[0,0],[1,0]] with x = 1 the left powers are 1, 0, 0, …, so p_1·p_2 = 1·0 = 1 ≠ 0 = p_3 and CL
fails, while p_a·p_a = p_(2a) and p_(2^k)·p_a = 0 = p_(a+2^k) hold. In [[0,1,1],[1,0,0],[1,1,0]], SQ, CL and CR
hold at every element but PA fails at some element. The table [[0,0,0],[0,0,0],[0,1,0]] satisfies PA at every
element but is not associative. ∎

## Remarks

1. **The usual sufficient condition.** If M is power-associative, all three algorithms are exact for every x
   (Proposition 5 with Theorems 1 and 2). The converse fails: in [[0,1,1],[1,0,0],[1,1,0]] all three algorithms are
   exact at every element (SQ, CL and CR hold there), but the magma is not power-associative.
2. **What is not needed.** Theorems 1 and 2 use no finiteness. Theorem 3 and Proposition 4 use only that the
   left powers of x are eventually periodic, for example because they take finitely many values; M itself may be
   infinite.
3. **Deciding PA(x).** With eventually periodic left powers, PA(x) holds iff p_a·p_b = p_(a+b) for all
   a, b ≤ μ + λ − 1. *Proof:* if a ≥ μ, then p_a and p_(a+b) do not change when a is replaced by the
   a′ ∈ [μ, μ + λ − 1] with a′ ≡ a (mod λ), since a + b ≥ μ as well; the same holds for b. So every instance of the
   condition equals one with a, b ≤ μ + λ − 1. verify.py uses this to decide PA for the witnesses of
   Proposition 5.
4. **Per element.** All statements are per element x. Binary powering is exact for every x iff the condition holds
   at every x.
5. **Number of products.** Write ν(e) for the number of 1 bits of e. LTR makes exactly ⌊log₂ e⌋ + ν(e) − 1
   products: one squaring for each of the ⌊log₂ e⌋ bits after the leading one, and one product r·x for each of the
   ν(e) − 1 of them that are 1. RTL needs s_1, …, s_K with K = ⌊log₂ e⌋ (the highest set bit), that is K squarings
   (s_(K+1) is not computed; a loop that squares after every bit makes one product more),
   and one product with r at each of the ν(e) − 1 set bits after the first; the total is the same. Since
   ν(e) − 1 ≤ ⌊log₂ e⌋, both make at most 2⌊log₂ e⌋ products. The count does not depend on the magma.

## Scope

- The note treats the three algorithms as defined above: LTR with the multiplication r·x on the right, and RTL with
  the squarings s_k = s_(k−1)·s_(k−1). Other variants (for example LTR with x·r, or sliding windows) need their own
  conditions and are not covered.
- "Exact" means equal to the left power p_e. In a magma, right powers or other bracketings can differ from p_e (in
  [[0,0],[1,0]] with x = 1, x·(x·x) = 1 but (x·x)·x = 0); the note does not compare with them.

## Literature search

The class `own` records that no source stating Theorems 1–3, Proposition 4 or the independence was found. The works
named below document the search and credit related notions; none of them is used as evidence. What was checked:
- 17 queries with generic keywords about binary exponentiation, square-and-multiply, addition chains,
  power-associativity, magmas, groupoids, non-associative powers and plenary or principal powers (4 on Crossref,
  5 on arXiv, 8 on OpenAlex).
- Read, in the parts named:
  - Etherington, *Researches in non-associative algebra* (D.Sc. thesis, University of Edinburgh, 1941), which
    reprints his papers I–X of 1937–1941: contents and introduction, paper I, paper II §§1–3, paper X §§1–3, and a
    keyword scan of the whole thesis. It develops the theory of primary shapes (factors absorbed one at a time, as in
    the left powers here) and plenary shapes (repeated squaring, as in the s_k here) and an arithmetic of the
    indices of non-associative powers. It states no condition for binary powering to return the left power.
  - Reed, *Algebraic structure of genetic inheritance* (Bull. Amer. Math. Soc. 1997): abstract, §3.2–3.4 and a
    keyword scan. §3.2 defines principal powers (x^i = x^(i−1)·x) and plenary powers (x^[i] = x^[i−1]·x^[i−1]) in
    commutative non-associative algebras; nothing on binary powering.
  - Albert, *Power-associative rings* (1948): introduction and §1. With Albert's right powers x^(k+1) = x^k·x (the
    left powers p_k of this note), a ring is power-associative if and only if x^α·x^β = x^(α+β) for all positive
    integers α, β: the ring version of the equivalence stated in Definitions. Power-associativity is the sufficient
    condition of Remark 1.
  - Osborn, *A generalization of power-associativity* (1964): pp. 1367–1368, an identity for commutative rings that
    generalises the power-associative identity.
  - Cardó, *Arithmetic and k-maximality of the cyclic free magma*: the arXiv version (arXiv:2407.17692v1; not
    compared with the 2019 journal version), abstract and introduction, on free magmas and their submagmas.

  None of them states the conditions of this note.
- Not accessible: Holgate, *Sequences of powers in genetic algebras* (1967); only an abstract fragment was seen.
  Genetic algebras are commutative, so there CL and CR coincide, and the distinction between the two right-to-left
  variants does not arise.

The conditions are elementary, and the note makes no claim that they are unknown.

## Verification

```bash
python theorems/binary-powering-exactness-in-magmas/verify.py
```

The script uses the Python standard library only, is deterministic (fixed seeds), needs no network and runs in a
few seconds on a laptop. It exits with code 0 only if every check passes. It checks:

- **Theorems 1(b) and 3, exhaustively for orders 2–5.** LTR and SQ at x read only the column of x and the diagonal of
  the table (2m − 1 cells), so all assignments of these cells with x = 0 cover every magma with m elements and every
  element (relabelling the elements makes x = 0 no restriction): 8, 243, 16 384 and 1 953 125 assignments. For
  every exponent e ≤ 4m + 4, the first wrong exponent is exactly 2a*, and a* ≤ μ + λ − 1 ≤ m whenever some
  a ≤ 2m + 2 fails (μ, λ the smallest preperiod and period).
- **Tightness** of Theorem 3 with the magma above, for m = 2, …, 12.
- **Theorem 2(b)** for K = 0, …, 5 and both variants: all 16 + 19 683 tables of orders 2 and 3 with every element,
  and 1 500 seeded random tables each of orders 4 and 5 (72 581 pairs of table and element). Here RTL is computed
  by the recursion RTL(2^k) = s_k, RTL(2^k + a) = RTL(a)·s_k (s_k·RTL(a) for RTL-R) of the proof of Theorem 2; a
  separate check compares this recursion with the literal bit loop for all e ≤ 64 on all tables of order 2 and
  every 7th table of order 3, with every element.
- **Proposition 4** against simulation of RTL (all e ≤ 64, and 4 seeded random e < 2^120) on every 7th table of
  order 3 with every element.
- **Proposition 5:** the 8 per-element witnesses (conditions and simulation of the three algorithms for all
  e ≤ 64) and the two further witnesses (Remark 3 is used to decide PA); and the bracketing example of the Scope.
- **Remark 5:** the number of products of the literal LTR and RTL loops, for all e ≤ 4 096.

These are computations on a finite scope. The proofs above are what establish the theorems.
